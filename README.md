# GridTwin AI

### AI-Powered Transformer Digital Twin & Load Balancing Simulation

GridTwin AI is a software-based digital twin simulation designed to monitor and visualize three-phase transformer loading and support intelligent load management.

## Features

- Interactive 3D transformer visualization
- Three-phase R-Y-B feeder monitoring
- Simulated phase current and ambient temperature
- Transformer load imbalance monitoring
- AI-based load prediction
- Three-phase load balancing algorithm

## Technology Stack

- Python
- Streamlit
- 3D Visualization
- AI/ML

## Getting Started

1. Clone this repository.
2. Install the required dependencies.
3. Run the Streamlit application.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Disclaimer

This project is a software-based simulation using simulated values. It is not directly connected to a physical transformer or electrical switching equipment.

## Project Purpose

To demonstrate digital twin technology and intelligent three-phase transformer load management through an interactive simulation.
